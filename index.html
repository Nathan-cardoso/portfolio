Bolsista | 2022 - 2023

Fui contemplado com uma bolsa acadêmica no ano de 2022, onde atuei como analista de dados pela UFERSA.

O projeto envolveu o desenvolvimento de uma aplicação web destinada a apoiar agentes de saúde na identificação de áreas com maior incidência de notificações de arboviroses. Minhas responsabilidades incluíram a coleta e organização de dados, a criação de um banco de dados, a análise detalhada dos dados e a aplicação de modelos estatísticos para prever futuros casos de Dengue, chikungunya e zika.

Tecnologias utilizadas

No decorrer deste projeto, tive a oportunidade de trabalhar com Python e suas bibliotecas especializadas em análise de dados, como pandas, Matplotlib, Statsmodels, Prophet, além de ferramentas como Excel e MySQL.

Desenvolvedor Freelancer | 2025 - atual

Atualmente, atuo como desenvolvedor freelancer full-stack, com foco em aplicações WEB.

Sou responsável por todo o ciclo de desenvolvimento, desde a coleta de requisitos até a implementação, testes e deploy, garantindo soluções robustas e eficientes para meus clientes.

Tecnologias utilizadas

Atualmente, trabalho com as tecnologia: Django, FastAPI, Node.js, React e AWS para desenvolvimento de aplicações WEB.
